Source and dependency audit — 2026-10-05

Main-200 archive comparison
Compared every Assets/Packages/ROS source snapshot in the reproducibility
directories of the two 10-run Original batches, the 80-run Original batch,
and the 100-run Easy batch against the release candidate.
Every compared file is byte-identical except CmdVelSubscriber.cs, whose sole
text difference is a Tooltip rewording removing the DWA example. No executable
logic differs in that file. Both archived main scene files match exactly.
This finding covers archived files only, not the entire runtime system.
