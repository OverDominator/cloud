New helper: Tools/ROS/check_perception_dependencies.py
Run under the intended ROS Python environment, optionally supplying --model-dir
with a downloaded model directory. The check neither downloads weights nor starts
ROS nodes. It checks module discovery and model file presence only; actual imports,
weight integrity, model loading and inference remain untested.

For another machine, prepare model files separately and set depth_model_path in
a user-owned copy of victim_color_detector.yaml; pass that file through the
victim_config launch argument. Model redistribution/licensing is not cleared here.
