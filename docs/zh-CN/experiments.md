## 主实验

Original 原始记录分为10、10和80轮三个批次，论文按一个100轮场景组报告：61轮完成、39轮超时。Easy 为100轮，92轮完成、8轮超时。保留原始批次文件用于溯源，不表示论文必须拆成三个对比组。

完成率分母仅包含有效终止记录。没有此类记录的启动失败和人工中断不在分母中。每轮主实验限时600秒；主实验配置禁用了主动倒退恢复。人工驾驶功能没有通过这些结果得到评价。

`source_snapshots/` 原样保留部分历史 Python 和 C# 文件，但没有覆盖所有依赖、参数及历史场景，因此不能直接替换当前代码来完整复现历史环境。连接器快照仍属于第三方内容。

## 补充实验

`right_left_angle.csv` 选取自 `Formal30_20261004_120550/summary.csv` 中的 RightAngle 与 LeftAngle。`end_wall_selected_rerun.csv` 来源为 `WallEndShort10_Rerun10_20261004_161704/summary.csv`。导出内容保留场景、轮次、初始偏航角、状态和用时；原始记录未改动。

每种配置各有10轮选定的成功单受困者任务。End Wall 曾根据先前结果简化并重新测试，因此这些批次不代表所有尝试。其计时起点与主任务记录器不同，用时不能直接比较，30轮也不能与200轮合并。

此前 End Wall 的结果及排除尝试保存在原始本地归档中。论文已讨论这一实验历史，但仓库公开说明仍需确保同样清楚。仓库不提供完整原始图像、全部传感器数据包或逐帧重放保证。

## 独立验证及视频演示

约205.6秒完成的发布验证与284.684秒完成的视频演示是两轮不同运行。二者都不增加主实验分母。当前发布相关代码与历史主实验配置也不能直接宣称完全一致。

跨场景完成率差异描述的是不同配置下的观察结果，不是控制变量实验测出的独立算法增益；零碰撞记录也不能独立证明完全没有物理接触。
