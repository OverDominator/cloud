# 发布检查清单

[返回中文首页](../../README.zh-CN.md)

本页按已有验证记录整理，英文发布清单已同步更新。

## 已有记录支持的进展

- 建立独立本地发布副本，保留主要场景、脚本、Unity 元数据及连接器。
- 排除缓存、论文制作材料、运行日志及发布范围外的替代规划代码。
- 保留四个主实验批次摘要、部分历史源码及单独的30轮选定补充结果。
- 现有电脑完成导入、独立构建、通信及完整自主任务验证。
- 完成真实演示视频、结果摘要和项目说明；仓库已位于 `OverDominator/cloud`。

`copy_manifest.csv` 记录初次复制时的路径与哈希；之后文件发生过清理和修改，因此它不是最终发布文件的统一哈希清单。

## 公开发布或承诺完整复现之前仍需完成

- 核实代码所有权、资源来源和项目整体许可证。
- 固定外部依赖提交及本地补丁，完善可合法分发的依赖准备方法。
- 消除或明确标注特定用户路径，说明端点配置和模型准备步骤。
- 在全新环境验证安装，不能用当前电脑的一次成功运行替代该测试。
- 验证人工驾驶、CSV 保存及返回 ROS 控制的行为，不推断任务自动暂停与恢复。
- 审查凭据、私人端点、用户名及内部路径；自动扫描不能替代人工检查。
- 确认仓库可见性及导师访问权限。
- 后续运行或发布状态变更时，同步维护中英文说明。

论文可以说明仓库存在，但私有期间应说明访问限制；公开发布前不应承诺任何读者都能直接访问。
