# 操作说明

[返回中文首页](../../README.zh-CN.md)

以下人工操作说明来自现有源代码，不能据此认定所有按键和模式切换都已在发布副本中重新验证。

## 自主运行

主要场景默认使用 ROS 速度控制。配置好外部依赖与通信后，任务层选择探索或受困者引导目标，FAR 提供路线，Unity 执行运动，并通过触发区占用及保持时间条件确认救援。

## 人工驾驶与记录

当 Game 视图获得键盘焦点时：

- `M`：切换 `RobotMovement` 的人工控制与 ROS 执行模式。
- `WASD` 或方向键：前进、后退及转向。
- 空格：清除运动输入；不要据此把它当作已经验证的系统级急停。
- `P`：保存驾驶演示记录。
- `R`：重置驾驶记录，不是重置整个搜救任务。

人工模式接管机器人运动时会禁用 `CmdVelSubscriber`。这是执行层切换，不表示 ROS 任务管理器已经暂停，也不证明安全的共享控制或任务恢复。ROS 任务可能继续运行，演示交接前需要受控测试。

CSV 输出到 `Application.persistentDataPath/ManualDemonstrations`，包含时间戳、Unity/ROS 位置、偏航角、测量速度、控制输入及接触信息。该记录器本身不保存相机帧或点云；退出人工模式或停止运行时也可能自动保存额外样本。

## 场景配置

使用 Unity 编辑器及附带的场景构建脚本配置环境。场景生成依赖特定对象名称及标签，受困者总数在任务开始时初始化。不能假设运行期间任意插入一个预制体，就能自动注册为有效救援目标。

火源对象用于表达仿真危险区域，不是经过验证的热物理模型。
